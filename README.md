# 🛡️ SpectreOps: Red Team Attack Emulation & Path Visualizer

SpectreOps is an interactive, educational cybersecurity application built with **Python**, **Streamlit**, and **Google Gemini Flash**. It simulates multi-stage ethical hacking attack vectors across a mock enterprise subnet and generates automated, professional Red Team assessment reports aligned with the **MITRE ATT&CK** framework.

## 🚀 Features
* **Interactive Subnet Topology:** Visualizes connected nodes (Routers, Web Servers, Databases, Workstations).
* **Live Attack Terminal:** Real-time animated terminal logs simulating reconnaissance and exploitation.
* **AI-Powered Assessment:** Automatically parses simulation telemetry using Gemini Flash to write executive summaries and blue team remediation guides.
